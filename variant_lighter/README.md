Lighter variant: glossy 3D slim lighter (on/off flame + animated shine) with street-art 3D **I.** / **S.** signatures.

Isolated from the sign-only pipeline — does not use `scene_volumetric3d.html`, `render_frames_sign`, or `*-sign.webm`.

```bash
HL_FRAMES=90 node capture_lighter.mjs
```

Outputs:
- `hyperlinks-space-sticker-lighter.webm` (512², ≤256 KB)
- `hyperlinks-space-emoji-lighter.webm` (100², ≤64 KB)
